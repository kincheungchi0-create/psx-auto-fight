# PSX Auto Fight

Simple Three.js **auto mode** demo: four low-poly characters fight each other with idle / walk / run / attack / hit / death clips.

## Credits

[PSX People Free](https://heyheythere.itch.io/psx-people-free) by heyheythere — CC BY 4.0

## Local

Open `index.html` via any static server (models need HTTP, not `file://`).
